PROJECT / 01 · VOICE AI

Voice Hiring Agent

From a candidate profile to a scheduled interview, with conversation at the center.

Match candidates→Screen by voice→Schedule interviews

The challenge

Recruiting teams spend hours reviewing profiles, conducting initial screenings, and coordinating calendars. The goal was to automate these repetitive steps with a conversational AI workflow.

What I built

  • An LLM matching pipeline using FastAPI and LangChain to shortlist candidates.
  • Automated outbound calls using Twilio and Pipecat for natural conversational screening.
  • Interview scheduling as part of the same screening workflow.

The outcome

Saved hours of manual recruiting effort by automating candidate screening and scheduling. My voice-agent work was also featured at a tech showcase.

  • FastAPI
  • LangChain
  • Pipecat
  • Twilio
  • LLM matching

PROJECT / 02 · MULTI-AGENT SYSTEMS

Unified Marketplace Agent

One conversational entry point for an entire airport’s passenger services.

Passenger intent→Specialized agents→Unified checkout

The challenge

Airport services span different tenants, catalogs, menus, and pricing. Passengers need a coherent experience while each airport entity needs its own configuration and catalog boundaries.

What I built

  • A multi-agent conversational system orchestrated with LangGraph and Gemini.
  • Dynamic multi-tenant configuration for catalog isolation, menu setup, and pricing.
  • A unified cart and checkout across passenger services.
  • GA4-compliant ecommerce funnel events to identify where users drop off.

The outcome

Consolidated airport passenger services into a unified conversational assistant with tenant-specific configuration and funnel visibility.

  • LangGraph
  • Gemini
  • Multi-agent
  • Multi-tenant
  • GA4

PROJECT / 03 · KNOWLEDGE & DATA

Unified Knowledge & Data Retrieval Platform

Ask in plain English. Find answers across documents and databases.

Natural language→RAG + NL2SQL→Grounded answers

The challenge

Useful information lives across unstructured documents and structured databases. Finding it shouldn’t require knowing where it is stored or how to write a SQL query.

What I built

  • A unified platform combining semantic document retrieval and natural-language database queries using CrewAI and Weaviate.
  • Hybrid keyword and semantic search with citation page tracking.
  • Redis caching for optimized sub-second responses.
  • A real-time voice streaming interface through Pipecat and Twilio for telephony-based queries.

The outcome

A common interface for retrieving knowledge and querying data, with traceable document citations and voice access.

  • CrewAI
  • Weaviate
  • Redis
  • NL2SQL
  • Pipecat
  • Twilio
